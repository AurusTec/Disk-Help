# Prompt: Site institucional — Disk Help (Auto e Residência)

Use este prompt para pedir a criação do site. A imagem de referência está em
`Disk-Help/image.png` (identidade visual e lista de serviços).

## Prompt

Crie um site institucional (landing page) para a empresa **Disk Help - Serviços Auto e
Residência**, usando como referência de identidade visual e de conteúdo a imagem em
`Disk-Help/image.png`.

**Sobre a empresa:**
- Nome: Disk Help
- Slogan: "Se tem um problema, DÁ UM HELP"
- Posicionamento: "Soluções completas para o seu dia a dia"
- Atuação desde 1998, prestadora de serviços residencial e empresarial
- Diferenciais: atendimento rápido e profissional, preço justo e garantia de serviço

**Identidade visual (extrair fielmente da imagem):**
- Cores principais: verde (marca/ícones) e vermelho (detalhes/CTA), fundo branco
- Logo "DH" estilizado com faixa vermelha, ícone de casa acima do logo
- Tipografia bold/condensada para títulos, estilo direto e confiável

**Serviços a listar (com ícone + nome, extraídos da imagem):**
Manutenção de ar-condicionado, Conserto de geladeira, Higienização de ar-condicionado,
Máquina de lavar, Reparo de microondas, Reparo de forno, Limpeza de placa solar,
Dedetização, Desentupimento, Serviços hidráulicos, Instalação de ar-condicionado,
Eletricista, Chaveiro.

**Estrutura do site:**
1. Hero com logo, slogan e CTA (ex.: "Solicitar orçamento" / WhatsApp)
2. Seção "Sobre" (desde 1998, confiança, residencial e empresarial)
3. Grid de serviços (ícone + nome, replicando os 13 serviços da imagem)
4. Seção de diferenciais (atendimento rápido, preço justo, garantia)
5. Seção de contato (telefone/WhatsApp, formulário simples, área de atendimento)
6. Footer com dados da empresa

**Requisitos técnicos e de design:**
- Site responsivo (mobile-first)
- Hierarquia visual clara, boa legibilidade, respeitando a paleta verde/vermelho/branco da marca
- Ícones dos serviços em estilo consistente (pode reaproveitar/recriar em SVG)
- Microanimações sutis (hover em botões/cards, entrada de seções no scroll) sem exagerar
- Botão de WhatsApp fixo/flutuante para contato rápido

**Skills a utilizar:**
- `brandkit` — para consolidar a identidade visual (cores, logo, tipografia) a partir da imagem de referência
- `image-to-code-skill` / `stitch-skill` — para traduzir os elementos visuais da imagem (grid de serviços, ícones, layout) em código
- `pick-ui-library` — para escolher a stack/lib de UI adequada
- `animate` / `animation-vocabulary` / `find-animation-opportunities` — para as microanimações
- `impeccable-skill` — para revisão final de UX, acessibilidade, hierarquia e responsividade
- `review-animations` — para revisar as animações aplicadas antes de finalizar

Ao final, faça uma revisão crítica do site gerado (com a `impeccable-skill`) e liste eventuais
ajustes de acessibilidade, hierarquia ou responsividade antes de considerar concluído.
