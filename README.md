# Disk Help

> **Se tem um problema, DÁ UM HELP.**

Site da **Disk Help Serviços Auto e Residência**, que presta serviços para casas e empresas em Goiânia e região desde 1998.

---

## ✨ Como funciona

O visitante toca nos serviços de que precisa, informa o bairro e a urgência, e o site **monta a mensagem pronta para enviar no WhatsApp**.

## 🛠️ Serviços

| Climatização | Eletrodomésticos | Hidráulica e elétrica | Segurança e cuidados |
|---|---|---|---|
| Instalação de ar | Geladeira | Serviços hidráulicos | Chaveiro |
| Manutenção de ar | Máquina de lavar | Desentupimento | Dedetização |
| Higienização de ar | Micro-ondas | Eletricista | Limpeza de placa solar |
| | Forno | | |

## 🚀 Como abrir

Não precisa instalar nada. Basta abrir o arquivo no navegador:

```
site/index.html
```

## ▲ Deploy na Vercel

1. Em [vercel.com/new](https://vercel.com/new), importe este repositório.
2. Não altere nada: o `vercel.json` já indica que o site está em `site/` e que não há build.
3. Clique em **Deploy**.

## 📁 Estrutura

```
Disk-Help/
├── site/
│   ├── index.html   → página
│   ├── styles.css   → visual
│   ├── app.js       → monta a mensagem do WhatsApp
│   └── favicon.svg
├── image.png        → panfleto original (referência)
├── PRODUCT.md       → contexto da empresa
├── DESIGN.md        → cores, fontes e componentes
└── vercel.json      → configuração de deploy
```
